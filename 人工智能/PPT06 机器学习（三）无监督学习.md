# PPT 06 机器学习（三）无监督学习

## 1. 无监督学习总览 + 距离/相似度 + K-means

- 监督学习：数据里有输入 $x$，也有标签 $y$
- 无监督学习：只有数据，没有标签
  - 无标签数据通常更便宜、更容易大量获得 
  - 从数据本身发现结构:哪些样本彼此**相似**、哪些**维度**最重要、数据可能来自哪些潜在**分布**
- 两类思路：
  - **化繁为简**(聚类和降维)
    - 聚类：把样本按相似分成几堆
    - 降维：把高维数据压到低维，去掉冗余信息
  - **无中生有**(生成模型)
    - 试图学出数据背后的生成机制
- **聚类**
  - 目标：把数据集中的样本划分为若干个不相交的子集（簇）
  - 好的结果：簇内相似度高，簇间相似度低
- 机器怎么知道像不像？**距离/相似度函数**
  - 将样本看成向量，就可以计算两个样本之间的距离，d越小，越相似。
  - 距离度量需要满足一些基本性质：（现实中有些相似性不一定能满足）
    - 非负性
    - 同一性：一个点到自己距离为 0，而且只有完全相同的两个点距离才是 0。
    - 对称性
    - 三角不等式
  - 闵可夫斯基距离（一组距离定义，概括了多个距离度量公式）

    $dist(x_i,x_j)=\left(\sum_{u=1}^{n}|x_{iu}-x_{ju}|^p\right)^{1/p}$

    当 $p=2$ 时，就是欧氏距离。它就是我们平时最熟悉的“直线距离”：

    $dist(x_i,x_j)=\sqrt{\sum_{u=1}^{n}|x_{iu}-x_{ju}|^2}$

    比如二维平面上点 $(0,0)$ 到 $(3,4)$ 的欧氏距离是 $\sqrt{3^2+4^2}=5$。

    当 $p=1$ 时，就是曼哈顿距离：

    $dist(x_i,x_j)=\sum_{u=1}^{n}|x_{iu}-x_{ju}|$

    它像是在城市街区里走路，不能斜着走，只能横着竖着走。比如 $(0,0)$ 到 $(3,4)$ 的曼哈顿距离是 $|3|+|4|=7$。
  - 在 K-means 里，最常用的是欧氏距离
- K-means （最经典的聚类算法之一）
  - 给定一个 $k$，把数据分成 $k$ 个簇，并为每个簇找一个中心点
    - 簇中的每一个数据点到对应簇中心点的距离应小于这些数据点到其他簇中心的距离。
  - $k$ ：分成几个簇。缺点：现实问题有时候不能提前知道要分几类
  - means：“均值”。中心点：当前簇里所有样本点坐标的平均值。
  - K-means 的核心循环：
    - 先随机放几个中心点，然后把每个点分给最近的中心；
    - 分完以后，每个簇重新计算均值作为新中心；
    - 然后再按新中心重新分配；
    - 如此反复，直到中心不怎么变了。
  - 即：最小化所有样本到所属簇中心的平方距离和。
  - 实际做聚类前，经常要标准化数据，因为聚类结果和距离关系大，比如特征量纲的差距

## 2. K-means流程、DBSCAN

我们用一个小例子走一遍。假设有 6 个点：

$P_1=(0,0)$，$P_2=(1,2)$，$P_3=(3,1)$，$P_4=(8,8)$，$P_5=(9,10)$，$P_6=(10,7)$。

设 $k=2$，也就是要分成两个簇。假设初始中心选为 $P_1=(0,0)$ 和 $P_2=(1,2)$。这只是随机开始，不代表它们就是最终中心。

第一轮分配时，每个点分别算到两个中心的距离。$P_1$ 到中心 $P_1$ 距离为 0，所以归第一簇。$P_2$ 到中心 $P_2$ 距离为 0，所以归第二簇。对于 $P_3=(3,1)$，它到 $(0,0)$ 的距离是 $\sqrt{10}$，到 $(1,2)$ 的距离是 $\sqrt{5}$，所以离 $P_2$ 更近，归第二簇。$P_4,P_5,P_6$ 明显都离 $(1,2)$ 比离 $(0,0)$ 更近，也归第二簇。

所以第一轮可能得到：

簇 A：$P_1$
簇 B：$P_2,P_3,P_4,P_5,P_6$

接着更新中心。簇 A 只有 $P_1$，所以中心还是 $(0,0)$。簇 B 的中心取五个点的坐标平均：

$x$ 坐标：$(1+3+8+9+10)/5=6.2$
$y$ 坐标：$(2+1+8+10+7)/5=5.6$

所以新中心变成：

簇 A 中心 $(0,0)$，簇 B 中心 $(6.2,5.6)$。

接下来第二轮重新分配。现在 $P_2=(1,2)$ 和 $P_3=(3,1)$ 会发现自己其实更接近 $(0,0)$，而 $P_4,P_5,P_6$ 更接近 $(6.2,5.6)$。于是簇变成：

簇 A：$P_1,P_2,P_3$
簇 B：$P_4,P_5,P_6$

再更新中心。簇 A 的中心：

$x=(0+1+3)/3=1.33$，$y=(0+2+1)/3=1$

所以簇 A 中心约为 $(1.33,1)$。

簇 B 的中心：

$x=(8+9+10)/3=9$，$y=(8+10+7)/3=8.33$

所以簇 B 中心约为 $(9,8.33)$。

再做下一轮分配，会发现 $P_1,P_2,P_3$ 仍然更接近簇 A，$P_4,P_5,P_6$ 仍然更接近簇 B。分配不变，中心也不再发生实质变化，于是算法收敛。

- 缺点：
1. 必须提前指定 $k$。实际中可以用肘部法、轮廓系数等方法辅助选 $k$
2. 初始中心影响结果，很可能停留在局部最优。实践中常用多次随机初始化，或者 K-means++ 来改善
3. 不适合复杂形状的簇
4. 对量纲和特征尺度敏感。K-means 前通常要标准化，让不同特征处于可比较尺度。
5. 对异常点敏感，中心被极端值影响

- DBCSCAN：
  - 基于密度的空间聚类算法，可以把足够密度的区域划分为簇，并在有噪声的空间中发现任意形状的簇。
  - 两个关键参数：$\epsilon$（领域半径） 和 MinPts（最小点数，若领域内至少有多少点说明足够密）
- 三类点：
  - **核心点**：$\epsilon$ 邻域内点数不少于 MinPts。也就是说，它周围很热闹，处在高密度区域内部。
  - **边界点**：不是核心点，但落在某个核心点的 $\epsilon$ 邻域里，在簇的边缘。
  - **噪声点**：既不是核心点，也不在任何核心点的邻域内，被当成离群点。

- DBSCAN 的过程：
  - 先找一个未访问点，看它是不是核心点。
  - 如果是核心点，就从它开始扩张，把它邻域里的点加入同一个簇；
  - 如果邻域里的某个点也是核心点，就继续从这个核心点往外扩张，直到密度连通区域都被纳入同一个簇。
  - 如果一个点既不能成为核心点，也连不到任何核心点，就标记为噪声。
  - **随机选择未标记样本、判断 $\epsilon$ 邻域数量、核心点扩展并合并、标记噪声、重复直到所有样本被访问。**

- DBSCAN 的优点
  - 不需要提前指定簇数，簇数由密度结构自然形成。
  - 能发现任意形状的簇
  - 能识别噪声点（K-means 往往会强行把每个点都分到某个簇里）

- 劣势：对 $\epsilon$ 和 MinPts 很敏感。如果不同簇的密度差异很大，同一个 $\epsilon$ 很难同时适合高密度簇和低密度簇。

- 如果你拿到一个二维散点图，看到几团比较圆的点，可以先试 K-means；如果看到月牙、环形、长条形，或者有很多离群点，就应该想到 DBSCAN 这类密度聚类方法。如果数据维度很高，聚类前还常常先做标准化，甚至先做 PCA 降维再聚类。

## 3. PCA 主成分分析：**数据维度太高时，怎么在尽量少丢信息的前提下降维？**

- PCA，全称 Principal Component Analysis，主成分分析。
- 经典**无监督降维方法**
- **降维**：就是把高维数据压到低维空间。
- 通过找到数据特征的主要成分，用这些主要成分**替代**原始数据，使样本在转换后的空间中**方差最大**。

- 为什么需要降维？
  - 计算和存储压力大
  - 很多维度是冗余的。比如两个特征高度相关，可以由少数几个主要方向解释
  - PCA 的思想：找出最重要的方向（**最大可分性**和**最近重构性**），保留主要变化。

- **最大可分性**
  - 数据投影到低维空间以后，样本之间尽量分开。点之间差异很明显，信息保留得多。
  - “点之间分得开”：**方差大**
- **最近重构性**
  - 从低维空间还原回原空间，还原出来的点应该尽量接近原来的点。
- 二者其实是一体两面

- PCA 和**协方差矩阵**
  - PCA 的基本流程：
    - 假设每个样本都是一个向量
    - 均值标准化（每个样本减去平均值，让数据中心移到原点附近）
    - 计算协方差矩阵，特征值分解(得到特征值和特征向量)，取前 $k$ 个特征向量。
    - 得到降维后的 $k$ 个主成分方向。
- 协方差矩阵：各个维度之间怎么一起变化
  - 某个方向上数据变化很大 -> 这个方向包含的信息多
  - 在线性代数里，**协方差矩阵的特征向量**就是这些特殊方向，而**特征值**表示对应方向上的**方差大小**。

- "主成分": 不是原始某一个特征,通常是**原始特征的线性组合**。
  - 比如原始特征是 $x_1$ 和 $x_2$，第一主成分可能是 $0.7x_1+0.7x_2$

- PCA 的经典应用
- Eigenface（特征脸）
  - 人脸图片本质上是高维向量。用 PCA 从一组人脸图像中找出主要变化方向，这些方向还原成图像后，看起来像一张张“特征脸”
- PCA 本身不看标签，它只是从人脸数据中找主要方向；但降维后的表示可以再拿去做人脸识别
- PCA 是一种**特征提取/降维方法**，可以作为**后续分类**、聚类、可视化的前处理。

- PCA 的优点：简单、经典、可解释性较强，能去除冗余信息，降低计算量，还能帮助可视化。
- 局限：
  - 线性降维，只能找线性方向。
  - 关注方差最大（但可能只是噪声）
  - 对数据尺度敏感，不同特征量纲需要先标准化

### 4. GMM 高斯混合模型与 EM 算法

- K-means 的聚类是 **hard assign** (硬分配)。
  - 一个点最后只能属于某一个簇。
- GMM(Gaussian Mixture Model)，高斯混合模型，是 **soft assign** (软分配)
  - 认为：一个样本可能来自第 1 个高斯分布，也可能来自第 2 个高斯分布，只是概率不同。
  - GMM 中每个样本根据后验概率 soft assign 到各个聚类。
- GMM 假设数据是由 $K$ 个高斯分布共同生成的。
  - 每个高斯分布对应一个潜在簇。
  - 第 $k$ 个高斯分布有自己的均值 $\mu_k$ 和协方差 $\Sigma_k$，还有一个混合系数 $\pi_k$。
  -  参数：$\theta={\pi,\mu,\Sigma}$
  -  $\pi_k$ ：第 $k$ 个高斯分布在整体中占多大比例。
  -  $\mu_k$ ：第 $k$ 个高斯分布的中心位置，像 K-means 的簇中心。
  -  $\Sigma_k$ ：第 $k$ 个高斯分布的协方差，描述这个簇的形状、方向和散布程度。
-  GMM 用“均值 + 协方差 + 概率密度”来判断归属，可以表达椭圆形、不同大小、不同方向的数据簇。
-  缺点：也会受初始化影响

- **隐变量**
  - 样本来自哪个分布的类别变量，通常记作 $z^{(i)}$
  - $z^{(i)}\in{1,\ldots,k}$ 表示第 $i$ 个样本对应的隐变量或簇标签变量。
- 我们要一边猜每个点属于各个高斯的概率，一边更新每个高斯的参数 --> EM 算法

- **EM** (期望最大算法): “估计概率归属—更新分布参数”
- **E-step：Expectation，期望步。**(依据当前参数，计算每个数据来自不同高斯分布的可能性)
  - 固定当前模型参数 $\pi,\mu,\Sigma$，计算每个样本来自每个高斯分布的概率(责任度)
- **M-step：Maximization，最大化步。**(根据E步软分配结果，重新计算类别中心和方差等参数)

- K-means 可以粗略理解成 GMM 的一个特殊、简化版本：
  - 如果每个高斯分布的协方差都相同、都是球形，而且最后只取概率最大的那个簇
- GMM 用于异常检测：（**密度估计模型**）
  - 如果某个样本在所有高斯分布下概率都很低，它可能就是异常点。

- 整理

第一个是样本 $x$，这是你观察到的数据。

第二个是隐变量 $z$，表示样本来自哪个高斯分布，但它不可见。

第三个是混合系数 $\pi$，表示每个高斯成分被选中的先验概率。

第四个是均值 $\mu$，表示每个高斯成分的中心。

第五个是协方差 $\Sigma$，表示每个高斯成分的形状和扩散程度。

第六个是后验概率 $P(z=k|x)$，表示已知样本 $x$ 后，它属于第 $k$ 个高斯分布的概率，也就是 E-step 要算的东西。
