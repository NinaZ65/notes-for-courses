---

先看 NLP 典型应用。复习 PPT 在 Transformer 之前先讲了一组自然语言处理任务：信息抽取、自动文摘、信息推荐、自动问答、机器翻译。它们不一定每个都会大题，但判断题和简答题可能会蹭到。

信息抽取，就是从自然语言文本中抽取指定类型的事实信息，并转成结构化数据。PPT 里列了实体识别、实体消歧、关系抽取、事件抽取。比如“小明在夏威夷度假”，命名实体识别要识别出“小明”是人名，“夏威夷”是地名。关系抽取则输出三元组，比如“北京是中国的首都”可以抽成“（中国，首都，北京）”。事件抽取更复杂，会抽出事件触发词和事件元素，比如“毛泽东 1893 年出生于湖南湘潭”，触发词是“出生”，元素有 Person、Time、Place。

考试写法：

信息抽取是从非结构化文本中抽取实体、关系、事件等事实信息，并形成结构化表示的技术。常见任务包括命名实体识别、实体消歧、关系抽取和事件抽取。

自动文摘就是把长文本自动压缩成短摘要。PPT 里强调要求：信息量足、覆盖面广、冗余度低、可读性高。自动文摘分为抽取式和生成式。抽取式是从原文中挑句子；生成式是重新组织和改写内容。

信息推荐就是根据用户习惯、偏好或兴趣，从大量信息中识别用户可能喜欢的内容。PPT 里提到协同过滤、基于内容的推荐、基于知识的推荐。协同过滤可以按用户相似性推荐，也可以按物品相似性推荐；基于内容的推荐会看物品属性，比如喜欢乡村音乐就推荐类似歌曲；基于知识的推荐依赖领域知识，不容易冷启动，但需要提前整理知识。

自动问答 QA 是从大规模文本中找出问题答案，结合知识表示、信息检索、自然语言处理和推理。PPT 把问答系统分成基于检索式和基于生成式。检索式更像“找答案”，生成式更像“组织答案”。

机器翻译就是把一种语言翻译成另一种语言。它从早期统计机器翻译，发展到神经网络机器翻译，后来 Transformer 成为非常重要的基础架构。

这几个 NLP 应用不需要死背细节，记成一张表就够：
信息抽取：从文本中抽实体、关系、事件。
自动文摘：长文变短摘要，抽取式/生成式。
推荐系统：根据用户兴趣推荐内容，协同过滤/内容/知识。
自动问答：根据问题找答案或生成答案。
机器翻译：源语言到目标语言。

接下来进入 Transformer。复习 PPT 里 Transformer 的核心是 **自注意力机制 self-attention**。它有一句非常重要的话：可以尝试用 self-attention 替代很多过去由 RNN 完成的事情。

RNN 是按顺序处理序列，前面的信息通过隐藏状态传到后面。问题是长距离依赖不好处理，而且并行性差。Transformer 的 self-attention 允许序列中每个 token 直接和其他 token 建立联系，所以更擅长捕捉长距离依赖，也更适合 GPU 并行计算。

考试写法：

Self-attention 使模型在处理某个 token 时，可以根据该 token 与序列中其他 token 的相关程度，对其他 token 的信息进行加权汇总，从而获得上下文相关的表示。相比 RNN 的顺序处理，self-attention 更容易捕捉长距离依赖，并且可以并行计算。

这也是真题里考过的方向：Transformer 中能判断一句话中的代词指代前面哪个对象，靠的就是自注意力机制。

---

Self-attention 里最重要的是 Q、K、V。

PPT 里写得很明确：q 是 query，用来 match others；k 是 key，用来 be matched；v 是 information to be extracted。

换成人话：

Query：当前 token 想找什么信息。
Key：每个 token 提供什么匹配特征。
Value：真正要被提取和汇总的信息。

计算过程可以这样理解：

每个 token 先生成自己的 Q、K、V。
当前 token 用自己的 Q 去和所有 token 的 K 做点积，得到相关性分数。
分数除以 $\sqrt d$ 做缩放，避免数值太大。
再经过 softmax 变成注意力权重。
最后用这些权重对所有 token 的 V 加权求和，得到当前 token 的新表示。

核心公式是：

$Attention(Q,K,V)=softmax(\frac{QK^T}{\sqrt d})V$

这公式考试可能让你解释，不一定让你算。你就按四段拆：

$QK^T$：算 token 之间的相关性。
$\sqrt d$：缩放，防止点积过大导致 softmax 太极端。
$softmax$：把相关性分数变成权重。
乘 $V$：按注意力权重汇总真正的信息内容。

考试写法：

Self-attention 中，Q 表示当前 token 查询的信息需求，K 表示各 token 可被匹配的特征，V 表示实际传递的信息。模型通过 $QK^T$ 计算 token 间相关性，经缩放和 softmax 得到注意力权重，再对 V 加权求和，得到融合上下文后的表示。

---

然后是多头自注意力 Multi-head Attention。PPT 里说，多头注意力允许模型从多个角度捕捉数据中的复杂关系，为注意力层提供多个表示子空间。

单头注意力就像只用一种视角看句子。多头注意力相当于同时用多个视角看：一个头可能关注主谓关系，一个头可能关注指代关系，一个头可能关注位置关系，一个头可能关注语义相似词。

考试写法：

多头自注意力将输入映射到多个不同的 Q、K、V 子空间中，分别计算注意力，再将多个头的结果拼接或融合。这样模型可以从不同表示子空间捕捉多种关系，提高对复杂上下文的建模能力。

---

再讲位置编码。Self-attention 本身有一个问题：它看的是 token 之间的相关性，但没有天然的顺序感。PPT 里也写了，self-attention 会丢失序列顺序信息，因此需要在输入词向量中加入位置信息。

比如“猫追狗”和“狗追猫”，词一样，但顺序不同，意思完全不同。Transformer 如果不加位置编码，很难知道谁在前谁在后。

位置编码的做法是：在 word embedding 上加 position embedding。PPT 里也说，每个 position 可以视为特殊 token，将 word embedding 和 position embedding 组合作为 Transformer 的 input；相同 word 在不同 position 会有不同 input。

考试写法：

由于 self-attention 本身不包含序列顺序信息，Transformer 需要加入位置编码来表示 token 在序列中的位置。位置编码通常与词向量相加，使相同词在不同位置具有不同输入表示，从而让模型感知词序。

所以 Transformer 基本三件套就是：

**Self-attention 建上下文关系；Multi-head 捕捉多角度关系；Position encoding 补充顺序信息。**

---

接下来是 BERT。PPT 里说 BERT 是 2018 年提出的大规模预训练语言模型，利用掩码机制构造基于上下文预测的预训练任务。BERT 在预训练时有两个输出层，对应两个任务：MLM 和 NSP。

BERT 的特点是偏向语言理解。它通过双向上下文学习表示，也就是一个词的表示既看左边，也看右边。

MLM 是 Masked Language Modeling，掩码语言建模。PPT 里说，BERT 会随机掩盖输入句子中 15% 的词，用 `[MASK]` 替换，然后让模型预测被遮住的词。这个任务像完形填空，目的是学习词级别的上下文关系。

NSP 是 Next Sentence Prediction，下一句子预测。给句子 A 和句子 B，模型判断 B 是否是 A 的下一句。PPT 里说这个任务用于学习句子级别的上下文关系，增强对文本关系的理解。

考试写法：

BERT 是一种大规模预训练语言模型，侧重语言理解。其预训练任务包括 MLM 和 NSP。MLM 随机遮盖输入中的部分词，让模型根据上下文预测被遮盖词；NSP 判断两个句子是否具有上下句关系，从而学习句子级语义关系。BERT 推动了“预训练 + 微调”的 NLP 范式。

---

然后是 GPT。GPT 全称 Generative Pre-trained Transformer，重点是生成。PPT 里梳理了 GPT-1、GPT-2、GPT-3 的变化。GPT-1 还有预训练和微调两阶段；GPT-2 更强调 scaling up，转向自然语言生成；GPT-3 通过 In-Context Learning，使模型无需更新参数也能做 zero-shot、one-shot、few-shot 推理。

GPT 的训练核心是预测下一个 token。也就是给前文，让模型预测下一个词元。所以它更偏生成。

考试写法：

GPT 是基于 Transformer 的生成式预训练语言模型，通常采用自回归方式，根据前文预测下一个 token。随着模型规模、数据规模和上下文长度扩大，GPT 系列逐渐表现出 zero-shot、one-shot、few-shot 和 in-context learning 能力，能够通过 prompt 适配不同任务。

BERT 和 GPT 的区别可以这样背：

**BERT 偏理解，双向看上下文，典型任务是 MLM/NSP。
GPT 偏生成，自回归预测下一个 token，典型能力是 prompt 和 in-context learning。**

---

接着是 ChatGPT 核心技术。PPT 里把它压成一句话：“学说人话，学人偏好，反馈强化”。

这里有几个必须知道的词：SFT、Prompt learning、Instruction tuning、LoRA、RLHF、CoT。

SFT 是 Supervised Fine-Tuning，监督式微调。它用高质量的“提示—回答”数据，让模型学会按照人类希望的方式回答问题。PPT 里也说，SFT/Instruction FineTuning 把各种任务统一成生成式自然语言理解框架，并构造训练语料进行微调，使模型具有更好的任务泛化能力。

考试写法：

SFT 使用人工构造或筛选的提示—回答样本对预训练语言模型进行微调，使模型学会按照指令生成更符合任务要求的回答。

Prompt learning 是给模型设计提示模板，让模型按提示完成任务。比如“老师讲得通俗易懂，学生很喜欢，这门课太____了。”模型补“好”。Instruction tuning 则是直接用自然语言指令训练模型，比如“判断这句话的情感是正向、中性还是负向”。PPT 里也对 Prompt-learning 和 Instruction-learning 做了对比。

考试区分：

Prompt learning 更像设计提示模板来引导模型完成任务。
Instruction tuning 是用大量指令任务微调模型，让模型学会遵循自然语言指令。

LoRA 是轻量级微调。PPT 里说，预训练模型参数 $W_0$ 固定不变，只训练 A 和 B 两个低秩矩阵；与 Transformer 结合时，通常在 QKV attention 计算中增加旁路。

考试写法：

LoRA 是一种大模型参数高效微调方法。它冻结原始预训练模型参数，只在部分权重旁路中加入低秩可训练矩阵，通过训练少量新增参数实现模型适配，从而降低显存和计算成本。

RLHF 是 Reinforcement Learning from Human Feedback，基于人类反馈的强化学习。PPT 里说，它通过人类偏好、评价或指导作为奖励信号，训练奖励模型，再用强化学习优化智能体策略，使行为与人类期望和偏好保持一致。

考试写法：

RLHF 通过收集人类对模型输出的偏好排序训练奖励模型，再利用该奖励模型作为反馈信号，通过强化学习优化语言模型，使模型输出更加符合人类偏好、安全规范和任务要求。

CoT 是 Chain of Thought，思维链。PPT 里说，CoT 能大幅提升常识推理能力、数学逻辑推理能力，使大语言模型更具可解释性和可信性。它的思想是让模型生成中间推理过程，而不只是直接给答案。

考试写法：

CoT 通过引导模型生成逐步推理过程，提高模型在数学推理、常识推理和复杂问题求解中的表现，也使模型答案具有更强的可解释性。

最后，这一讲压缩成考试版：

NLP 应用：信息抽取、自动文摘、推荐、问答、机器翻译。

Self-attention：用 Q 和 K 算相关性，用 softmax 得权重，再对 V 加权求和。

Q：当前 token 想找什么。
K：每个 token 提供什么匹配信息。
V：真正被汇总的信息。

Multi-head attention：多个注意力头，从不同子空间捕捉关系。

Position encoding：补充序列位置信息，解决 self-attention 本身不含词序的问题。

BERT：偏理解，MLM + NSP，预训练 + 微调。

GPT：偏生成，自回归预测下一个 token，prompt / in-context learning。

SFT：用提示—回答样本教模型按指令回答。
Prompt learning：设计提示模板引导模型。
Instruction tuning：用大量指令任务训练模型遵循指令。
LoRA：冻结原模型，只训练低秩旁路参数。
RLHF：用人类偏好训练奖励模型，再强化学习优化输出。
CoT：让模型生成推理链，提高复杂推理能力。
