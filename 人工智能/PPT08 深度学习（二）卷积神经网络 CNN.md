# PPT 08 深度学习（二）卷积神经网络 $CNN$

## 1. 卷积神经网络结构上的三大特性：局部连接、权重共享、下采样

1. 局部连接：全连接层里，一个神经元要看整张图；卷积层里，一个神经元(卷积核)只看图像的一小块区域
2. 权重共享：同一组权重在不同位置重复使用；同一种局部视觉模式在不同位置出现时，应该可以用同一种检测方法识别。
3. 下采样：常见模式**池化**；把特征图尺寸变小，计算量下降，神经元感受野变大

- 卷积层负责提取局部特征，池化或下采样负责压缩空间尺寸
- 前面用卷积层和池化层做特征提取，后面用全连接层做综合判断。

## 2. 卷积操作详解

- 卷积基本过程：
  - 拿一个小窗口**（卷积核kernel/filter）**在图像上滑动
  - 每滑到一个位置，就对这个局部区域做一次加权求和
  - 得到输出特征图（feature map）上的一个数
  - 下一层在上一层生成的这个特征图上卷积
- 某一个卷积核对某一种特征敏感，其特征图显示的是某个特征在一张图上的分布强度
- 感受野：单个卷积核在**原图**上的“视野”
  - 卷积核盖住原图左上角 $3 \times 3$ 的小方块，做一次加权求和，得到输出特征图左上角的一个数。这个输出数是由原图这 $3 \times 3$ 个像素算出来的，所以它的感受野就是原图里的这个 $3 \times 3$ 区域。
  - 层数越深，单个神经元实际能看到的原图范围越大，感受野更大
- **padding（填充）**：就是在图像边缘补一圈或多圈数字，最常见是补 0
  - 1. 控制输出尺寸
  - 2. 边缘信息不至于太快丢失
  - 很多 CNN 里喜欢用 $3 \times 3$ 卷积、padding=1 的原因：它可以在提取局部特征的同时保持空间尺寸不变。
- **stride（步长）**：卷积核每次滑动的步长
  - 步长越大，输出特征图越小，计算量越低，但也更容易丢失细节。
  - 可以起到下采样效果

综合 padding 和 stride，输出边长的一般公式是：（一般向下取整）

$$
\left\lfloor \frac{n+2p-k}{s} \right\rfloor + 1
$$

这里 $n$ 是输入边长，$p$ 是 padding，$k$ 是卷积核边长，$s$ 是 stride。

- 卷积输出的空间尺寸由 $n,p,k,s$ 决定，但输出通道数不是由这个公式决定的，而是由卷积核的个数决定的。
- 比如你用了 32 个卷积核，那么就会生成 32 张 feature maps，输出通道数就是 32。

## 3. 多通道卷积、多个卷积核、参数量、池化层和全连接层

把卷积核解释成一个立方体，而不是单纯二维小矩阵

- 单通道输入 + 单个卷积核
  - 比如输入是一张 $3 \times 3$ 灰度图
- 单通道输入 + 多个卷积核
  - 实际 CNN 中，一层卷积通常会有很多个卷积核
  - 多个卷积核提取多种特征，生成多张feature maps
  - 输出通道数 = 卷积核个数
- 多通道输入 + 单个卷积核
  - 比如输入是一张 RGB 图片，有 3 个通道
  - 一个卷积核会同时看所有输入通道，并把所有通道上的卷积结果加总，生成一张输出 feature map。
- 多通道输入 + 多个卷积核 （实际 CNN 最常见的情况）
  - 假设输入有 $C_i$ 个通道，输出想要 $C_o$ 个通道，那么就需要 $C_o$ 个卷积核。每个卷积核的深度都等于输入通道数 $C_i$，每个卷积核都会生成一张 feature map。最后把 $C_o$ 张 feature maps 叠起来，得到输出张量。
  - 所以整层卷积的权重形状可以理解成：

    $C_o \times C_i \times k_h \times k_w$

参数量计算：

$$
params = C_o \times (k_w \times k_h \times C_i + 1)
$$

这里 $C_o$ 是输出通道数，也就是卷积核个数；$C_i$ 是输入通道数；$k_w \times k_h$ 是卷积核空间大小；最后的 $+1$ 是每个卷积核对应一个 bias。

- 注意，参数量和输入图片的高宽没有直接关系。计算量会变大，因为滑动位置变多。但因为共享参数，参数量不会变多。
- 全连接层参数量通常和输入维度直接相关。

- 计算量 FLOPs（浮点运算量）：
  - 卷积层计算量大致取决于“每个输出点需要多少乘加运算 × 输出点总数 × 输出通道数”。
  - 所以计算量和输出特征图的宽高有关，也和输入通道数、输出通道数、卷积核大小有关。

- 池化层 pooling：
  - 卷积层虽然显著减少了连接个数，但每个 feature map 上的神经元个数并没有显著减少，所以需要池化来进一步压缩。
  - **max pooling**：如果某个局部区域里已经检测到了某种强特征，那么我们只保留最强响应即可，不必保留每一个精确位置。
  - **average pooling**：保留平均强度
    - 现代常见global average pooling：把每个通道整张 feature map 平均成一个数
  - 池化层通常没有可学习参数，是固定规则。会改变 feature map 的空间尺寸，但一般不改变通道数。

- 全连接层：
  - 和常规神经网络中一样，本质是矩阵乘法再加偏置
  - CNN 前面的卷积层和池化层负责提取空间特征，最后通常需要把这些特征用于分类。
  - 早期 CNN 的做法是把最后的 feature maps 拉平成一维向量，然后送入全连接层
  - 缺点：参数量容易很大。

假设输入是一批图片，batch size 是 $N$，输入张量形状是：

$N \times 3 \times 64 \times 64$

经过卷积层：

Conv2d(in_channels=3, out_channels=16, kernel_size=3, stride=1, padding=1)

输出空间尺寸保持 $64 \times 64$，输出通道数变成 16，所以输出形状是：

$N \times 16 \times 64 \times 64$

这一层参数量是：

$16 \times (3 \times 3 \times 3 + 1) = 448$

再经过 $2 \times 2$ max pooling，stride=2，空间尺寸减半，通道数不变：

$N \times 16 \times 32 \times 32$

如果再接一个卷积层：

Conv2d(16, 32, kernel_size=3, stride=1, padding=1)

输出形状变成：

$N \times 32 \times 32 \times 32$

参数量是：

$32 \times (3 \times 3 \times 16 + 1)=32 \times 145=4640$

再池化一次：

$N \times 32 \times 16 \times 16$

如果最后要分类，就可以把每张图拉平成：

$32 \times 16 \times 16 = 8192$


维向量，再接全连接层输出类别。

## 4. 经典CNN：LeNet、AlexNet、VGG、Inception、ResNet、DenseNet

- 怎么更深、怎么更准、怎么更省参数、怎么更稳定训练
- 图像分类（what）、目标检测（what&where）、图像语义分割（每个像素属于什么类别）、图像实例（同一类不同个体分开）分割
  - 如果下采样太狠，空间信息丢太多，分类可能还能做，但检测和分割会受影响
- ImageNet ：推动 CNN 爆发的重要大型图像数据集和竞赛平台
  - 让 AlexNet、VGG、Inception、ResNet 这些网络有了统一竞技场

- 经典网络：
  - LeNet（定下CNN基础，证明 CNN 可以用于图像识别）
    - 手写数字识别
    - 输入 → 卷积 → 池化 → 卷积 → 池化 → 全连接 → 输出
  - AlexNet
    - 分组卷积（硬件限制下，多个GPU时）、第一次使用 ReLU（解决深层网络训练困难）、data augmentation（数据增强，解决的是数据不够和过拟合问题）、dropout=0.5（随机丢掉一部分神经元）、batch-size=128、SGD momentum=0.9、learning-rate=1e-2、weight-decay=5e-4。
    - 卷积层参数只占总参数的一小部分，而全连接层参数占绝大多数
  - VGG
    - 用更深的网络和更小的卷积核（小卷积核组合可以降低参数量，且非线性更多）
    - $3 \times 3$ conv-filter，stride=1，padding=1，以及 $2 \times 2$ pooling
    - $3 \times 3$ 是能表达上下、左右、中心这些局部关系的最小常用卷积核。
    - 如果堆两个 $3 \times 3$ 卷积，感受野相当于一个 $5 \times 5$；堆三个 $3 \times 3$，感受野相当于一个 $7 \times 7$。但这样做比直接用大卷积核更有优势。
  - Inception / GoogLeNet
    - 在同一层并行使用多种卷积核尺度，把结果在通道维度拼接起来
    - “拼接”：通道加起来，空间尺寸保持一致，通道数增加。
    - 并行多个卷积核会带来参数和计算量问题
      - $1 \times 1$ 卷积（bottleneck 瓶颈层）。作用主要是通道变换和降维
      - eg.先用 $1 \times 1$ 卷积把通道数从 256 降到 32，再做 $3 \times 3$ 卷积
    - Batch Normalization、非对称卷积、全局平均池化
      - BN 的直觉是在训练中把每一层输入拉回比较标准的分布，可以防止梯度消失或爆炸，加快训练速度
  - ResNet
    - **恒等映射**：传统神经网络训练函数 $F(x)$，加入恒等映射后变成 $F(x)+x$，模型相当于学习对 $x$ 的修正量，这个修正量叫残差。
    - 通过残差连接解决深层网络退化和训练困难，使得非常深的 CNN 可以有效训练。
  - DenseNet
    - 每一层都接收前面所有层的输出作为输入
    - ResNet 的“加”要求两边形状一致，输出通道数不变；DenseNet 的“拼接”是在通道维度把前面层的特征都保留下来，使深层网络更容易优化。
