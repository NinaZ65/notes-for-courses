## 定位索引

| 题目关键词                                                                 | 先翻哪里              | 主要抄什么                                                |
| --------------------------------------------------------------------- | ----------------- | ---------------------------------------------------- |
| **block、NameNode、DataNode、BlockMap、小文件、写流程、副本放置**                     | **第1章 HDFS**      | HDFS架构、元数据、写流程、容错、不适合小文件                             |
| **Map、Reduce、Shuffle、Combiner、Partitioner、Split、WordCount、伪代码**       | **第2章 MapReduce** | 编程模型、WordCount、MR流程、split/block/partitioner/combiner |
| **RowKey、Region、MemStore、HFile、WAL、Compaction、LSM-tree、Feed流**        | **第3章 HBase**     | HBase模型、物理存储、读写流程、表结构设计                              |
| **Spout、Bolt、Tuple、Stream、Grouping、Topology、shuffle/fields**          | **第4章 Storm**     | 计算模型、Bolt链路设计、Grouping选择、系统架构                        |
| **RDD、Transformation、Action、DAG、Stage、Task、窄依赖、宽依赖、lineage**          | **第5章 Spark**     | RDD、惰性执行、Stage切分、Task生成、容错                           |
| **Dremel、嵌套数据、列式存储、r/d、repetition、definition、FSM**                    | **第6章 Dremel**    | r/d赋值规则、Code/Country表、FSM拼回记录                        |
| **Flink、Event Time、Watermark、State、Checkpoint、Savepoint、Keyed State** | **第7章 Flink**     | 时间水印、状态类型、状态后端、检查点/保存点                               |
| **NoSQL、Key-value、Document、Column-family、Graph、ACID、CAP、BASE、最终一致性**  | **第8章 NoSQL**     | 四种数据模型、CAP、ACID/BASE、一致性定义                           |
| **HDFS vs HBase、MR vs Spark、Storm vs Flink、Spark vs Flink、综合设计题**     | **第9章 综合速查**      | 对比表、通用答题模板、伪代码模板                                     |

HDFS范围对应课件里的背景、架构、访问和小文件管理；MapReduce强调离线处理特点；HBase课件明确补足 GFS/MapReduce 不支持随机实时读写的需求；Storm课件强调实时流式、Topology、Spout/Bolt/Grouping；Spark课件强调MR性能问题、RDD和DAG；Dremel课件重点是嵌套列式存储和 r/d；Flink课件重点是时间、水印、状态、检查点和与Spark/Storm对比；NoSQL课件重点是数据模型、CAP和一致性。
