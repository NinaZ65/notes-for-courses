## 第6章 Dremel｜开卷速查版

**本章一句话：** **Dremel** 是 Google 用来做超大规模嵌套数据交互式分析的系统。它的核心难点是：数据原本是 **嵌套记录**，但为了查询快，要按 **列式存储**；列式拆开以后，还要能靠 **repetition level / definition level** 把结构拼回去。🌙

**常考题型：** 给嵌套数据表，要求给某一列填 **r / d**；给列式数据，要求基于 **FSM** 拼回记录；解释 **r 和 d 的含义**；解释为什么 Dremel 能只读部分列还保留嵌套结构。

**翻页关键词：** Nested data model → repeated / optional / required → Column-striped representation → r/d → Code/Country例子 → Encoding → Record assembly FSM → 拼回表。

---

### 1. Dremel 解决什么问题

Dremel 面向的是 **web-scale datasets**，也就是万亿级记录、多 TB 数据，目标是做交互式分析查询。PPT里列出它的特点：支持 trillion-record / multi-terabyte datasets、可扩展到 thousands of nodes、fault tolerant execution、nested data model、columnar storage and processing、tree architecture。

它要解决的问题可以压成一句话：

**原始数据是复杂嵌套结构，但查询时常常只需要其中几列；如果整行读，会浪费 I/O；如果按列存，又会丢失嵌套结构。Dremel 用 r/d 两个 level 在列式存储中保留嵌套结构。**

**考试写法：**
Dremel 是用于大规模嵌套数据交互式分析的系统。它采用列式存储来减少查询时读取的数据量，同时为每个值保存 repetition level 和 definition level，从而在只读取部分字段的情况下仍能恢复原来的嵌套记录结构。

---

### 2. Nested Data Model：嵌套数据模型

Dremel 的数据不是普通二维表，而是 **strongly typed nested record**，即强类型嵌套记录。每个字段可以是原子类型，也可以是 record/group。

PPT里有三种字段修饰：

**required：** 必须出现，不能缺失。
**optional / ?：** 可选字段，可以出现，也可以为空。
**repeated / *：** 重复字段，可以出现 0 次、1 次或多次。

PPT示例 schema 是：

```text
message Document {
  required int64 DocId;

  optional group Links {
    repeated int64 Backward;
    repeated int64 Forward;
  }

  repeated group Name {
    repeated group Language {
      required string Code;
      optional string Country;
    }
    optional string Url;
  }
}
```

简单理解：

**DocId**：每条记录必须有一个。
**Links**：可选，有可能没有。
**Backward / Forward**：在 Links 里面可以重复多次。
**Name**：一个 Document 可以有多个 Name。
**Language**：一个 Name 下面可以有多个 Language。
**Code**：Language 里必须有。
**Country**：Language 里可选。
**Url**：Name 里可选。

---

### 3. 为什么列式存储会有问题

普通行式记录长这样：

```text
DocId: 10
Links:
  Forward: 20
  Forward: 40
  Forward: 60
Name:
  Language:
    Code: en-us
    Country: us
  Language:
    Code: en
  Url: http://A
Name:
  Url: http://B
Name:
  Language:
    Code: en-gb
    Country: gb
```

如果按列存，就会把它拆成：

```text
DocId
Links.Forward
Links.Backward
Name.Url
Name.Language.Code
Name.Language.Country
```

这样查询 `Name.Language.Country` 时只读这一列，确实省 I/O。但问题是：**只看到 Country 这一列时，怎么知道某个值属于哪个 record、哪个 Name、哪个 Language？**

所以 Dremel 给每个列值附加两个标签：

```text
(value, r, d)
```

其中：

**r = repetition level，重复层级**
**d = definition level，定义层级**

PPT中明确写：Dremel 给每个 value 增加两个整数标签，r 表示 repetition level，d 表示 definition level。

---

## 4. r / d 一句话定义

**r：repetition level**
表示当前值是从路径上的哪个 **repeated 字段** 开始重复的。它主要回答：**这是新 record，还是同一个 record 里的新 Name / 新 Language？**

**d：definition level**
表示当前值所在路径上那些可能不存在的字段，也就是 **optional 或 repeated 字段**，实际出现了几层。它主要回答：**这个值到底定义到了哪一层？是真有值，还是某一层缺失导致 NULL？**

PPT原意是：r 表示 value 在字段路径上的哪个 repeated field 发生了重复；d 表示路径中可能 undefined 的字段有多少个实际存在。

**考试写法：**
Repetition level 表示当前值相对于前一个值，从哪一个 repeated 字段开始重复，用于区分新记录、新 Name 或新 Language。Definition level 表示字段路径上 optional 或 repeated 字段实际存在到哪一层，用于区分真实值和由于某层缺失产生的 NULL。

---

## 5. d 怎么赋值：Definition Level

先看字段路径里有哪些 **可能不存在** 的节点。一般来说，**optional 和 repeated 都算一层 definition**；required 不增加 definition level。

### 例1：`Name.Language.Code`

路径：

```text
Document.required
 -> Name.repeated
 -> Language.repeated
 -> Code.required
```

其中可能不存在的是：

```text
Name      repeated
Language  repeated
```

Code 是 required，所以不额外加一层。

因此：

```text
Name.Language.Code 的最大 d = 2
```

含义：

```text
d = 0：连 Name 都没有
d = 1：Name 有，但 Language 没有
d = 2：Name 和 Language 都有，因为 Code required，所以 Code 有真实值
```

所以 Code 列中：

```text
en-us   d=2
en      d=2
NULL    d=1    // 有 Name，但没有 Language，所以没有 Code
en-gb   d=2
NULL    d=1
```

### 例2：`Name.Language.Country`

路径：

```text
Document.required
 -> Name.repeated
 -> Language.repeated
 -> Country.optional
```

可能不存在的是：

```text
Name       repeated
Language   repeated
Country    optional
```

因此：

```text
Name.Language.Country 的最大 d = 3
```

含义：

```text
d = 0：Name 都没有
d = 1：Name 有，但 Language 没有
d = 2：Name 和 Language 有，但 Country 没有
d = 3：Name、Language、Country 都有，Country 是真实值
```

所以 Country 列中：

```text
us      d=3    // Country 有真实值
NULL    d=2    // Language 有，但 Country 缺失
NULL    d=1    // Name 有，但 Language 缺失
gb      d=3
NULL    d=1
```

**d 判题口诀：**
**沿路径数 optional / repeated，存在几层就是 d；如果 d 小于最大 d，就说明某层缺失，值是 NULL。**

---

## 6. r 怎么赋值：Repetition Level

r 只和路径上的 **repeated 字段** 有关。它表示“当前值和前一个值相比，是从哪一层 repeated 字段开始重复的”。

还是看 `Name.Language.Code` 或 `Name.Language.Country`：

路径上的 repeated 字段有两个：

```text
Name       repeated   -> level 1
Language   repeated   -> level 2
```

再加上 record 开始：

```text
record     -> r = 0
Name       -> r = 1
Language   -> r = 2
```

含义：

```text
r = 0：新 record
r = 1：同一个 record 里，开始一个新的 Name
r = 2：同一个 Name 里，开始一个新的 Language
```

用 PPT 示例的 `Name.Language.Code` 列：

```text
value    r    d
en-us    0    2
en       2    2
NULL     1    1
en-gb    1    2
NULL     0    1
```

解释：

**en-us, r=0：** 第一条记录的第一个 Name 的第一个 Language。
**en, r=2：** 还是同一个 Name，只是多了一个 Language。
**NULL, r=1：** 同一个 record 里新的 Name，但这个 Name 没有 Language。
**en-gb, r=1：** 同一个 record 里又一个新的 Name，这个 Name 有 Language。
**NULL, r=0：** 新 record，里面有 Name，但没有 Language。

**r 判题口诀：**
**新 record，r=0；同 record 新 Name，r=1；同 Name 新 Language，r=2。**

## 7. 关键列：`Name.Language.Code`

这是 PPT 重点页，直接背表：

```text
Name.Language.Code

value    r    d
en-us    0    2
en       2    2
NULL     1    1
en-gb    1    2
NULL     0    1
```

解释版：

```text
en-us：
  第一条 record 开始，所以 r=0；
  Name 和 Language 都存在，Code required，所以 d=2。

en：
  同一个 Name 下的第二个 Language，所以 r=2；
  Name 和 Language 都存在，所以 d=2。

NULL：
  同一个 record 下的新 Name，所以 r=1；
  这个 Name 没有 Language，所以 d=1。

en-gb：
  同一个 record 下的新 Name，所以 r=1；
  Name 和 Language 都存在，所以 d=2。

NULL：
  新 record，所以 r=0；
  这个 record 里有 Name，但 Name 没有 Language，所以 d=1。
```

**考试写法：**
对于 `Name.Language.Code`，路径中有两个 repeated 字段：Name 和 Language，因此 r 的最大值为 2；路径中可能缺失的字段也是 Name 和 Language，Code 是 required，因此 d 的最大值为 2。r=0 表示新 record，r=1 表示同一 record 中新的 Name，r=2 表示同一 Name 中新的 Language；d=2 表示 Code 存在，d=1 表示 Name 存在但 Language 缺失。

## 8. 关键列：`Name.Language.Country`

也直接背表：

```text
Name.Language.Country

value    r    d
us       0    3
NULL     2    2
NULL     1    1
gb       1    3
NULL     0    1
```

解释版：

```text
us：
  新 record，所以 r=0；
  Name、Language、Country 都存在，所以 d=3。

NULL：
  同一个 Name 下的新 Language，所以 r=2；
  Language 有，但 Country 这个 optional 字段缺失，所以 d=2。

NULL：
  同一 record 下的新 Name，所以 r=1；
  Name 有，但 Language 没有，所以 d=1。

gb：
  同一 record 下的新 Name，所以 r=1；
  Name、Language、Country 都存在，所以 d=3。

NULL：
  新 record，所以 r=0；
  Name 有，但 Language 没有，所以 d=1。
```

**注意：**
`Code` 和 `Country` 的 r 一样，因为它们路径上的 repeated 字段一样，都是 Name 和 Language。区别在于 **d 最大值不同**：Code required，最大 d=2；Country optional，最大 d=3。

## 9. 其他列的 r/d 速查

### `DocId`

路径：

```text
Document -> DocId.required
```

没有 optional，也没有 repeated，所以：

```text
最大 r = 0
最大 d = 0
```

表：

```text
DocId

value    r    d
10       0    0
20       0    0
```

### `Links.Forward`

路径：

```text
Document
 -> Links.optional
 -> Forward.repeated
```

可能缺失字段：Links、Forward，所以最大 d=2。
repeated 字段：Forward，所以最大 r=1。

表：

```text
Links.Forward

value    r    d
20       0    2
40       1    2
60       1    2
80       0    2
```

解释：

```text
20：新 record，r=0；Links/Forward 都存在，d=2
40：同一 record 下 Forward 重复，r=1
60：同一 record 下 Forward 重复，r=1
80：新 record，r=0
```

### `Links.Backward`

表：

```text
Links.Backward

value    r    d
NULL     0    1
10       0    2
30       1    2
```

解释：

```text
NULL：
  第一条 record 有 Links，但没有 Backward，所以 d=1。
10：
  第二条 record 开始，所以 r=0；Links 和 Backward 都存在，d=2。
30：
  同一 record 下 Backward 重复，所以 r=1；d=2。
```

### `Name.Url`

路径：

```text
Document
 -> Name.repeated
 -> Url.optional
```

可能缺失字段：Name、Url，所以最大 d=2。
repeated 字段：Name，所以最大 r=1。

表：

```text
Name.Url

value      r    d
http://A   0    2
http://B   1    2
NULL       1    1
http://C   0    2
```

解释：

```text
http://A：
  新 record，第一个 Name，有 Url。

http://B：
  同一 record 下新的 Name，有 Url，所以 r=1,d=2。

NULL：
  同一 record 下新的 Name，但 Url 缺失，所以 r=1,d=1。

http://C：
  新 record，第一个 Name，有 Url，所以 r=0,d=2。
```

## 10. r/d 计算题统一步骤

考试看到让你填 r/d，就按这四步：

```text
1. 写出字段路径。
2. 标出路径上的 repeated 字段，决定 r 的层级。
3. 标出路径上的 repeated + optional 字段，决定 d 的最大值。
4. 按实际记录逐个值判断：
   - 是新 record，r=0；
   - 是同 record 新的外层 repeated，r=对应外层；
   - 是同外层里新的内层 repeated，r=对应内层；
   - d 看路径实际存在到哪一层。
```

模板句：

**r 看重复从哪一层开始，d 看定义到哪一层。**

或者更短：

```text
r 管“重复层级”
d 管“缺失层级”
```

## 11. Encoding：Dremel 怎么真正存

PPT里说每一列按 block 存储，每个 block 包含 repetition levels、definition levels 和压缩后的字段值；NULL 不显式存储，任何小于最大 definition level 的 d 都表示 NULL；level 会被打包成 bit sequence。

**重点：**
表格里写 `NULL` 是为了讲解结构，实际存储时不一定真的存一个字符串 NULL。Dremel 通过 d 判断这里是缺失值。

**考试写法：**
Dremel 的每一列被存储为多个 block，每个 block 包含 repetition level、definition level 和压缩后的字段值。NULL 通常不显式存储，而是通过 definition level 表示：当某个值的 d 小于该字段路径的最大 definition level 时，说明路径中某一层缺失，因此对应值为 NULL。

---

## 12. Record Assembly FSM 是什么

**FSM = Finite State Machine，有限状态机。**

它用来把列式数据重新拼回记录。PPT中 Record assembly FSM 页面说明：FSM 的状态与字段路径有关，边上标的是 repetition level；对于面向记录的数据处理，如 MapReduce，FSM 会对每条 record 从开始状态走到结束状态一次。

你可以这样理解：

**r 决定回退到哪一层，再从那一层继续拼；d 决定这条路径实际生成到哪一层。**

比如读取 `Name.Language.Country` 时：

```text
r=0：新 Document
r=1：同一个 Document 里开新的 Name
r=2：同一个 Name 里开新的 Language
```

再看 d：

```text
d=3：Country 有真实值
d=2：Language 有，但 Country 没有
d=1：Name 有，但 Language 没有
```

---

## 13. 基于 FSM 拼回表：通用规则

考试如果给列式数据让你拼回嵌套结构，就按这个规则写。

```text
1. 读当前列值的 (value, r, d)。
2. 如果 r=0，说明开始一条新 record。
3. 如果 r>0，根据 r 回退到对应 repeated 层：
   r=1：开新的 Name
   r=2：开新的 Language
4. 根据 d 判断结构定义到哪一层：
   d=max：叶子字段有真实值
   d=max-1 或更小：某层缺失，填 NULL 或不生成叶子字段
5. 持续读取，直到下一个 r=0 开启下一条 record。
```

**答题模板：**
利用 FSM 拼回记录时，先根据 repetition level 判断当前值是新记录还是某个 repeated 字段的新实例；再根据 definition level 判断字段路径实际存在到哪一层。如果 d 达到最大 definition level，则填入真实值；如果 d 小于最大值，则说明路径中某个 optional/repeated 字段缺失，只生成已定义到的结构。

## 14. 拼回例子：只看 `DocId` 和 `Name.Language.Country`

给定两列：

```text
DocId

value    r    d
10       0    0
20       0    0
```

```text
Name.Language.Country

value    r    d
us       0    3
NULL     2    2
NULL     1    1
gb       1    3
NULL     0    1
```

拼回逻辑：

**第一行 Country：`us, r=0, d=3`**

```text
r=0：新 record，对应 DocId=10
d=3：Name、Language、Country 都存在
```

拼出：

```text
DocId: 10
Name:
  Language:
    Country: us
```

**第二行：`NULL, r=2, d=2`**

```text
r=2：同一个 Name 里新的 Language
d=2：Name 和 Language 存在，但 Country 缺失
```

拼出：

```text
Name:
  Language:
    Country: us
  Language:
    Country: NULL / absent
```

**第三行：`NULL, r=1, d=1`**

```text
r=1：同一个 record 里新的 Name
d=1：Name 存在，但 Language 缺失
```

拼出：

```text
Name:
  // no Language
```

**第四行：`gb, r=1, d=3`**

```text
r=1：同一个 record 里新的 Name
d=3：Name、Language、Country 都存在
```

拼出：

```text
Name:
  Language:
    Country: gb
```

**第五行：`NULL, r=0, d=1`**

```text
r=0：新 record，对应 DocId=20
d=1：Name 存在，但 Language 缺失
```

拼出：

```text
DocId: 20
Name:
  // no Language
```

最后结构大致是：

```text
DocId: 10
Name:
  Language:
    Country: us
  Language:
    Country: NULL
Name:
  // no Language
Name:
  Language:
    Country: gb

DocId: 20
Name:
  // no Language
```

注意：如果题目要求严格还原原 PPT 记录，并且同时给了 `Name.Language.Code`，那第二个 Language 有 `Code=en`，只是 `Country` 缺失；只读 Country 时只能知道 Country 缺失，但不能知道 Code 的具体值。

```text

```

## 16. Code 和 Country 的区别：最容易考的点

`Name.Language.Code` 和 `Name.Language.Country` 路径很像，但：

```text
Code 是 required
Country 是 optional
```

所以：

```text
Code 最大 d = 2
Country 最大 d = 3
```

它们的 r 一样：

```text
r=0 新 record
r=1 新 Name
r=2 新 Language
```

它们的 d 不一样：

```text
Code:
  d=2 才有 Code
  d=1 表示 Name 有但 Language 没有

Country:
  d=3 才有 Country
  d=2 表示 Language 有但 Country 没有
  d=1 表示 Name 有但 Language 没有
```

**考试写法：**
`Code` 是 required 字段，因此只要 Name 和 Language 存在，Code 就存在，最大 definition level 为 2；`Country` 是 optional 字段，即使 Name 和 Language 存在，Country 也可能缺失，因此最大 definition level 为 3。二者路径上的 repeated 字段相同，所以 repetition level 的含义相同。

## 17. 本章高频简答模板

**1. Dremel 为什么需要 r/d？**
Dremel 将嵌套记录按列存储以减少查询 I/O，但列式存储会打散原有的嵌套结构。为了在只读取部分列时仍能恢复记录结构，Dremel 为每个值保存 repetition level 和 definition level。r 表示重复从哪一层开始，d 表示字段路径实际定义到哪一层。

**2. repetition level 是什么？**
Repetition level 表示当前值相对于前一个值，是从字段路径上的哪个 repeated 字段开始重复的。它用于区分新 record、同一 record 中的新 Name、同一 Name 中的新 Language 等结构重复关系。

**3. definition level 是什么？**
Definition level 表示字段路径中 optional 或 repeated 字段实际存在了多少层。若 d 达到该字段的最大 definition level，则叶子字段有真实值；若 d 小于最大值，则说明路径中某层缺失，对应值为 NULL 或 absent。

**4. 为什么 `Name.Language.Code` 最大 d 是 2？**
因为该路径中可能缺失的字段是 repeated 的 Name 和 repeated 的 Language，而 Code 是 required，不额外增加 definition level。因此最大 d 为 2，表示 Name 和 Language 都存在时 Code 必然存在。

**5. 为什么 `Name.Language.Country` 最大 d 是 3？**
因为该路径中可能缺失的字段包括 repeated 的 Name、repeated 的 Language 和 optional 的 Country。Country 自身可缺失，因此最大 definition level 为 3。

**6. FSM 如何拼回记录？**
FSM 根据 repetition level 判断当前值是新 record 还是某个 repeated 字段的新实例，再根据 definition level 判断字段路径实际存在到哪一层。r 控制结构回退和重复，d 控制是否填入真实值或生成缺失结构。

---

## 18. 本章易混点

**r 不是“重复次数”。**
r 表示从哪一层 repeated 字段开始重复，不是第几个值。

**d 不是“深度总层数”。**
d 只数路径上可能缺失的字段，也就是 optional 和 repeated；required 不算缺失层。

**NULL 不一定真实存储。**
讲解表里写 NULL 是为了表示结构缺失，实际存储中通常靠 definition level 表示 NULL。

**Code 和 Country 的 r 一样，d 不一样。**
因为它们 repeated 路径一样，但 Country 是 optional，Code 是 required。

**r=0 一般表示新 record。**
看到 r=0，通常就要开启下一条记录。

**d 达不到最大值，说明叶子值不存在。**
比如 Country 最大 d=3，d=2 表示 Language 存在但 Country 缺失。

## 19. 本章看到题目怎么写

看到“**解释 r/d**”：写 r 管重复层级，d 管定义/缺失层级。

看到“**给 Code 填 r/d**”：路径是 `Name repeated -> Language repeated -> Code required`，最大 r=2，最大 d=2。

看到“**给 Country 填 r/d**”：路径是 `Name repeated -> Language repeated -> Country optional`，最大 r=2，最大 d=3。

看到“**为什么列式还能拼回嵌套结构**”：写每个值带 r/d，r 保留重复关系，d 保留缺失关系。

看到“**基于 FSM 拼回表**”：先看 r，新 record / 新 Name / 新 Language；再看 d，判断真实值还是某层缺失。

看到“**计算题**”：先写路径，再标 repeated 层级，再标 optional/repeated 的 definition 层级，最后逐行填表。
